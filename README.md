# 전국 전통 스토리 지도 (웹 + 앱)

명소 × 인물·설화 → 미디어아트 IP를 전국 지도로. 점을 누르면 그 도시의 연결 컨셉이 뜨고, 제작(초인)·배우기(케이에브리데이)로 연결.

## 파일
- `index.html` — 본체(지도 메인 + 상세 패널)
- `data.js` — 링크 설정(`LINKS`) + 도시 데이터(`CITIES`)
- `app.js` — 지도·패널 로직
- `manifest.webmanifest`, `sw.js`, `icon-192/512.png` — PWA(앱 설치용)

## 1. 그냥 열기 (웹, 로컬)
`index.html` 더블클릭 → 브라우저에서 바로 열림. (인터넷 필요 — 지도·라이브러리 CDN)

## 2. 링크 바꾸기 (먼저 할 일)
`data.js` 맨 위 `LINKS`의 초인·케이에브리데이 주소를 실제 채널/사이트로 교체.

## 3. 앱처럼 쓰기 (PWA)
PWA 설치는 https로 띄워야 동작. 아래 배포(깃허브 페이지스) 후, 폰 브라우저에서 접속 → "홈 화면에 추가" → 아이콘 설치(오프라인도 됨).

## 4. 배포 (무료, 깃허브 페이지스)
1) 깃허브에 새 저장소(예: `story-map`) 만들고 이 폴더 파일 업로드
2) Settings → Pages → Branch: main / root → 저장
3) 몇 분 뒤 `https://<아이디>.github.io/story-map/` 로 공개

## 5. 도시 추가/갱신
- 간단히는 `data.js`의 `CITIES`에 `['도시','권역',경도,위도,'A','연결 컨셉']` 한 줄 추가.
- 노션 〈전국 미디어아트 IP 지도〉 DB와 자동 동기화는 `sync_notion.py`(추후) 사용 — DB → data.js 재생성.

## 데이터 출처
